# Audio orphelin

Chaque enregistrement est rangé dans un dossier, qui appartient normalement à un livre du catalogue. Un dossier **orphelin** est un dossier qui n'appartient à aucun livre. Cette page les rassemble pour qu'aucun enregistrement ne se perde.

L'URL de cette page est https://eca-aveugles.fr/admin/audio-orphelins

![Audio orphelin - les dossiers à traiter](/admin/aide/images/audio-orphelin-01.jpg)

## Les trois onglets

- **À traiter** — les dossiers sur lesquels personne n'a encore rien décidé.
- **Rattachés** — les dossiers désormais reliés à un livre.
- **Écartés** — les dossiers sans valeur (essai, doublon, rebut).

## Rattacher un dossier à un livre existant

Recherchez le livre, puis sélectionnez-le : le dossier lui est rattaché. La page vous propose aussi des livres dont le titre ressemble au nom du dossier.

## Créer un livre pour ce dossier

Si le livre n'existe pas encore dans le catalogue, cliquez sur « **Créer un livre pour ce dossier** ». Le formulaire est prérempli à partir du nom du dossier : vérifiez le titre avant de valider. La durée ne se saisit pas : elle est mesurée sur les fichiers du dossier.

Le rattachement comme la création sont refusés si une autre fiche utilise déjà ce dossier — y compris une fiche supprimée avec l'option « laisser le dossier » : elle le revendique toujours, et la restaurer ferait deux fiches sur un même enregistrement. Le message nomme la fiche en cause.

## Écarter un dossier

Pour écarter un dossier, indiquez un motif. Un dossier écarté par erreur peut être restauré depuis l'onglet « Écartés ».

## Détacher

Si un dossier a été rattaché au mauvais livre, cliquez sur « détacher » : il retourne dans « À traiter ». Les fichiers ne sont pas touchés.

## Corbeille audio

Les fichiers audio supprimés passent d'abord par la corbeille — voir [Corbeille audio](/admin/aide/corbeille-audio).
