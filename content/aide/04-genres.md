# Genres

Comme le concept est simple, la page est tout aussi simple. Lorsque vous y accédez, vous y trouvez (1) un tableau répertoriant les genres existants, (2) un champ de recherche pour les trouver, et (3) un bouton permettant d'en créer de nouveaux. L'URL de cette page est https://eca-aveugles.fr/admin/genres.

![Genres - capture 1](/admin/aide/images/genres-01.jpg)

## Ajout de genres

Lorsque vous cliquez sur le bouton « Ajouter un genre », le modal d'ajout de genre s'ouvre.

![Genres - capture 2](/admin/aide/images/genres-02.jpg)

Saisissez le titre et la description du genre, puis cliquez sur « Créer le genre » pour l'enregistrer.

Pour modifier un genre, cliquez sur le bouton « Modifier » situé sur la ligne du genre que vous souhaitez modifier, ou cliquez n'importe où sur cette ligne.

![Genres - capture 3](/admin/aide/images/genres-03.jpg)

Cela ouvre la fenêtre contextuelle de modification du genre, dans laquelle vous pouvez (1) modifier le titre, (2) modifier la description, (3) suivre le lien vers le catalogue pour voir toutes les œuvres associées, (4) supprimer le genre, et (5) mettre à jour le genre.

![Genres - capture 4](/admin/aide/images/genres-04.jpg)
